# CineMatch — рекомендательная система фильмов

Учебный проект: рекомендации популярных фильмов, по жанру, по похожему названию и по ID пользователя.

## Состав проекта
- `api.py` — FastAPI backend.
- `movie_recommender_web/` — frontend (HTML, CSS, JavaScript).
- `artifacts/` — сохранённые данные и матрицы обученных моделей, необходимые API.
- `data/` — исходные данные MovieLens и промежуточные данные.
- `movie_recommender.ipynb` — ноутбук с подготовкой данных, обучением и оценкой моделей.
- `requirements_api.txt` — зависимости для запуска API.

## Запуск готового проекта на Windows

Нужен установленный Python.

Откройте CMD в папке проекта (там, где находятся `api.py` и `requirements_api.txt`) и выполните:

```bash
py -m pip install -r requirements_api.txt
py -m uvicorn api:app --host 127.0.0.1 --port 8000
```

Не закрывайте это окно. Откройте второе окно CMD в той же папке и выполните:

```bash
py -m http.server 5500 --bind 127.0.0.1 --directory movie_recommender_web
```

Откройте сайт: http://127.0.0.1:5500

Проверка API: http://127.0.0.1:8000/health  
Документация API: http://127.0.0.1:8000/docs

## Важно
- Не удаляйте папку `artifacts`: в ней лежат готовые файлы моделей, без них API не запустится.
- Для запуска уже обученной модели TMDB-токен не требуется. Токен нужен только при повторном выполнении ячейки ноутбука, которая загружает метаданные из TMDB.
- Не публикуйте API-токены и секреты в GitHub.
- Команды запуска не содержат личных путей Windows и подходят для любого расположения папки проекта.
